## 🇨🇳 中文

把角色图片、剧本片段或一句情绪短语，整理成可执行的分时微表情表演指导，用于让角色的情绪更自然、更细腻、更像真实演员。它支持三种输入：图片模式给一张角色图继续设计表演，剧本模式给剧本、分镜或提示词只增强表演层，情绪短语模式只需一句情绪或关系状态。流程先保护已确认的角色身份、场景、台词、调度和运镜，再确认镜头时长与表演强度，随后按需组合情绪路线、可见的面部与身体细节、节奏密度和镜头连续性约束。用户审阅提示词后，可生成可选的表演片段。它不替代完整编剧、面部绑定、口型编辑或最终合成。

### ✨ 能做什么

- 三种入口：角色图 / 剧本分镜 / 一句情绪短语
- 先锁定已确认的身份、场景、台词、调度与运镜 → 不让表演改动污染其他层
- 确认镜头时长与表演强度 → 再组合情绪路线与可见面部、身体细节
- 输出分时表演提示词 → 标明节奏密度与镜头连续性约束
- 用户审阅提示词后再生成 → 可选产出一段表演片段
- 专攻克制、含泪强撑、犹豫、愤怒、心动、冷静决绝等复杂表演

## 🇬🇧 English

Turns a character image, a script segment or a single emotion phrase into an executable, time-segmented micro-expression performance guide, so on-screen emotion reads as natural, restrained and actor-like. Three input modes are supported: image mode continues from one character still, script mode enhances only the performance layer of a script, storyboard or prompt, and emotion-phrase mode needs just a mood or relationship state. The workflow first protects the approved identity, scene, dialogue, blocking and camera intent, then confirms shot duration and intensity, and finally composes emotion routes, visible facial and body cues, timing density and continuity guardrails. After the user reviews the prompt, an optional performance clip can be generated. It does not replace full scriptwriting, facial rigging, lip-sync editing or final compositing.

### ✨ What it does

- Three entry points: character image, script/storyboard, or a one-line emotion phrase
- Locks approved identity, scene, dialogue, blocking and camera first → performance edits stay contained
- Confirms shot duration and intensity → then composes emotion routes with visible facial and body cues
- Outputs a time-segmented acting prompt → timing density and continuity constraints stated per beat
- Generates only after the user reviews the prompt → optional performance clip delivered
- Tuned for restrained, tearful, hesitant, angry, affectionate or quietly decisive moments
